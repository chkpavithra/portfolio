# Pavithra Chandrasekhar — Portfolio

A Next.js (App Router) + React + TypeScript portfolio with a Microsoft Fluent
theme and an animated Microsoft 365 Copilot ribbon.

## Run it

```bash
npm install     # install dependencies
npm run dev     # develop at http://localhost:3000
npm run build   # production build
npm run start   # serve the production build
```

## Content

All portfolio content (experience, certifications, education, skills, contact)
lives in **one file**: `src/data/portfolio.ts`. Edit that file to update the
site — every section reads from it.

No phone number is displayed anywhere on the site; contact is LinkedIn and
email only.
